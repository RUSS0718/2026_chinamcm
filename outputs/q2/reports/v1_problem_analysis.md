## 目标、输入与输出

在题面给定的正方形轮廓内布局可旋转矩形模块，最小化网络 HPWL，同时满足边界和无正面积重叠约束。输入为 `.blocks` 的模块、`.nets` 的网络引脚关系和 `.pl` 的 Terminal 绝对坐标。题面已确认死区比例 `d=0.15`；若模块总面积为 `A_B`，正方形边长为 `L=sqrt(A_B*(1+0.15))`，轮廓为 `(0,0)` 到 `(L,L)`。模块引脚按模块中心，Terminal 不因轮廓缩小而移动或被强制位于轮廓内。

输出为布局、方向、`W,H,area,aspect_ratio,rho,deadspace,HPWL`、合法性与运行元数据；HPWL 为各网络所有模块中心引脚和 Terminal 绝对坐标的横向跨度与纵向跨度之和的总和。

## 约束、依赖与最终结果

- 显式：布局在固定轮廓内；模块可旋转且不正面积重叠；网络所有引脚均纳入 HPWL。
- 隐式：Terminal 坐标绝对固定；边界接触允许；无合法解、超时和崩溃均保留而非替换。
- 依赖第 0 轮固定轮廓、中心引脚、Terminal、HPWL 和死区口径；复用 Q1 的表示/解码接口但不能沿用 Q1 的面积目标。
- 最终需比较合法率、HPWL、首次合法解时间、同预算效率及失败计数；均待运行。

## 候选比较

| 编号 | 路线与作用 | 优点 | 风险/数据可行性 | 回退条件 |
|---|---|---|---|---|
| Q2-SP (P0) | Sequence Pair + 经典 SA + 固定轮廓处理 | 表示独立、适合作可信基线 | 三类附件已齐全；固定轮廓可行性搜索成本较高 | 始终保留 |
| Q2-BT (P1) | B*-Tree + Fast-SA + 可行性优先约束 | 复用 Q1 主干并直接面向固定轮廓 | 罚函数权重不当会卡在不可行域或早熟 | P2 不能保持合法率时使用 |
| Q2-HG (P2) | P1 + 网络超图感知初始化 | 利用 `.nets` 高阶连接先验，目标与 HPWL 直接相关 | 聚簇过强可能牺牲轮廓可行性，收益须配对种子验证 | 关闭刚性簇保留软初始化；仍降低合法率则回退 P1 |

## 算法与开关

1. 冻结解析版本并校验网络引用与 Terminal 集合。
2. 用表示解码布局；先判断轮廓和重叠，再在可行解间比较 HPWL。
3. 以一致预算进行多起点搜索，记录首次合法时刻和评价次数。
4. `adaptive_constraints` 控制可行性优先约束，`hypergraph_init` 控制网络感知初始化；分别 OFF/ON 消融。

## 风险与 V2 证据

正方形轮廓、`d=0.15`、HPWL 目标和中心引脚已由正式题面确认；V2 仍需固定浮点容差、罚函数/可行性比较规则、参数来源、实际入口与运行证据。高阶网络和固定 Terminal 可能导致初始化偏置，每份正式布局须由独立审计复算 HPWL。
